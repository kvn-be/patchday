# Sidebar

The one way to move through Patchday: five places, always visible.

The consumer provides `pd-sidebar pd-glass`, the `pd-brand` with the mark drawn inline, one `pd-nav` per place with its icon, `aria-current="page"` on the open one, and the updates count in `pd-count` (hidden at 0).

- Always this order: Overview, Updates, Packages, Schedule, History.
- The foot holds Settings, the language `Segmented`, the coffee button and the version line, in that order.
- The selected place is solid white. Hover brightens the others.
- 248px wide, 26px radius. Nothing else in the app is a sidebar.
