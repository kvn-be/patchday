# Switch

An on and off control for settings that save by themselves.

The consumer provides a `<button class="pd-switch" role="switch" aria-checked="…">` with an empty `span` inside, a visible label next to it, and flips `aria-checked` on click.

- On is `ink`, off is a light grey track. The thumb is always white.
- Put the label first and a one-line hint below it, as on the Schedule page.
- No save button: a switch takes effect at once.
