# AppHeader

The bar at the top of the app and the website, with the mark, the name, the version badge and the three tools.

The consumer provides the version text and wires the language, theme and coffee controls.

- It stays visible while scrolling, so the coffee button is always in view.
- Always keep this order: mark, name, badge, then `LanguageSwitch`, theme button and coffee button on the right.
- Below 520px hide the version badge and the coffee label, and keep the cup.
