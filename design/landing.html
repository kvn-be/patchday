Patchday

Your updates run every Sunday at 03:00, with a backup first, a health check after, and a rollback if anything fails.

Get for macOS Get for Windows

One run, from start to report

  1. Check

    Homebrew, winget and Docker containers are listed.

  2. Back up

    Stack files and databases are saved first.

  3. Update

    One stack at a time, with Docker itself last.

  4. Test

    Up to 5 minutes for everything to run healthy again. If not, it rolls back.

  5. Report

    You see what ran and what needs your decision.

Fixed rules, no surprises

Runs automatically
  • Patch updates for healthy containers
  • Minor updates without breaking changes
  • Homebrew and winget
Suggestion only
  • Major updates
  • Databases and caches
  • Network, DNS and beta images
Never
  • Delete volumes or databases
  • docker system prune
  • Change stacks behind Portainer's back

Install, pick a time, done

macOS

Download from GitHub

Use arm64 for Apple silicon and x64 for Intel. The app is not signed yet, so open it once via System Settings > Privacy & Security > Open Anyway.

Windows

Download from GitHub

The app is not signed yet, so Windows shows a warning. Select More info, then Run anyway.

macOS with Homebrew

brew install --cask kvn-be/tap/patchday
